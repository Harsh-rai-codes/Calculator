                                             Calculater

A simple and responsive calculator website built using HTML, CSS, and JavaScript. It allows users to perform basic arithmetic operations through a clean, interactive, and user-friendly interface directly in the browser.

Features:
Perform basic calculations (+, −, ×, ÷)
Responsive and modern website design
Interactive buttons with smooth user experience
Real-time input and result display
Error handling for invalid operations

Tech Stack:
HTML – Structure of the website
CSS – Styling and layout design
JavaScript – Functionality and logic

Purpose:
This project was created to strengthen front-end web development skills and demonstrate how HTML, CSS, and JavaScript can be combined to build an interactive website.
